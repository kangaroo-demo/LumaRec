LumaRec 1.0.0

macOS 13+ · Apple Silicon (arm64) · English / 简体中文

Stable community release — locally signed, not Apple notarized. macOS may block the first launch. Use only macOS’s normal per-app approval. Never disable system security.
  1. Drag LumaRec.app to Applications. Eject the disk image, then open the app from Applications.
  2. If macOS blocks it as unverified, dismiss the message and open System Settings → Privacy & Security → Open Anyway for LumaRec; confirm Open if offered. Only approve a trusted official download. If that option is unavailable, stop and report the message.
  3. Allow Camera and Microphone. Select your devices; wait for the preview and check the audio meter.
  4. Choose a folder, record, pause/resume, and Stop to save an MP4. Wait for export before quitting. Silent needs only Camera permission.

This first release is for Apple Silicon only; Intel has no qualified download. No runtime installation, terminal commands, accounts, uploads or network needed. Input/Mix require an optional, separately configured virtual audio device; microphone recording does not.

Unfinished originals: Help → Recover recordings. Select any recording and retry export. Originals remain until successful export and are not encrypted. Damaged captures may not be repairable.

安装 LumaRec · 流光录

社区正式版：仅有本地临时签名，未经过 Apple 公证。 macOS 可能拦截首次启动。仅使用系统对单个应用的正常允许路径，请勿关闭系统安全机制。
  1. 将 LumaRec.app 拖入应用程序，推出磁盘映像，再从“应用程序”打开。
  2. 如系统因开发者未验证而拦截，关闭提示，前往系统设置 → 隐私与安全性 → 仍要打开，针对 LumaRec 确认打开。仅允许可信的官方项目下载；如无此选项，请停止并反馈提示。
  3. 允许访问摄像头和麦克风，选择设备，等待预览并确认说话时电平有变化。
  4. 选择保存目录后开始录制，可暂停或继续，停止后等待 MP4 导出完成再退出。无声模式只需摄像头权限。菜单栏 Language → 简体中文 切换语言。

首版仅面向 Apple 芯片，Intel 暂无已验收下载。无需安装运行环境、无需终端、账号、上传或网络。“输入/混合”需要另行配置的可选虚拟音频设备；麦克风录制无需虚拟驱动。

帮助 → 恢复录制 可选择任意未完成的素材重新导出。原始素材保留到导出成功，未加密；严重损坏的录制可能无法修复。

Published installers retain the accepted bytes; candidate wording inside their bundled guides is historical. 已发布安装包保持验收时原样，包内“候选”字样为历史记录。 1.0.0 stable release / 正式版.
