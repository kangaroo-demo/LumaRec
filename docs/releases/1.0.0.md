LumaRec 1.0.0 records your Mac camera and microphone and saves MP4 using Apple's native media frameworks. No Homebrew, FFmpeg, Xcode, terminal, account or runtime download is needed to use the app.

**LumaRec 1.0.0 is the first stable community release for Apple Silicon.** This build is ad hoc signed, **not Developer ID signed or Apple notarized**. macOS may block first launch. Its normal per-app approval is System Settings → Privacy & Security → Open Anyway, where offered. Do not disable system security. The owner currently has no paid Apple Developer account; this is a disclosed distribution limitation, not a promise of notarization.

- Apple Silicon (arm64) app; macOS 13+ deployment target. Intel is not qualified for this first release and has no download.
- H.264/AAC MP4; landscape/clockwise portrait, three quality levels and native mixed audio.
- Preview, audio meter, folder/device preferences, pause/resume and English/Simplified Chinese.
- New Silent mode; microphone permission is optional for video-only recording.
- Continuous 30 fps export clock holds missing camera frames without shifting audio.
- Persistent original MOVs and selectable recovery after failed export; final exports do not overwrite existing files.
- System audio still requires an optional configured virtual input. Native speaker-output capture is not included.

Use the DMG: drag LumaRec to Applications, eject and open. ZIP includes the same app and offline bilingual instructions. Check the attached SHA256SUMS file against your download. See the build metadata for the exact source revision and architectures.
