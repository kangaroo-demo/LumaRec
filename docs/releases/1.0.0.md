LumaRec 1.0.0 records your Mac camera and microphone and saves MP4 using Apple's native media frameworks. No Homebrew, FFmpeg, Xcode, terminal, account or runtime download is needed to use the app.

**Candidate for review; stable publication is pending the acceptance items in the release handoff.** This build is ad hoc signed, **not Developer ID signed or Apple notarized**. macOS may block first launch. Its normal per-app approval is System Settings → Privacy & Security → Open Anyway, where offered. Do not disable system security. The owner currently has no paid Apple Developer account; this is a disclosed distribution limitation, not a promise of notarization.

- Universal app for Apple Silicon and Intel; macOS 13+ deployment target.
- H.264/AAC MP4; landscape/clockwise portrait, three quality levels and native mixed audio.
- Preview, audio meter, folder/device preferences, pause/resume and English/Simplified Chinese.
- New Silent mode; microphone permission is optional for video-only recording.
- Persistent original MOVs and selectable recovery after failed export; final exports do not overwrite existing files.
- System audio still requires an optional configured virtual input. Native speaker-output capture is not included.

Use the DMG: drag LumaRec to Applications, eject and open. ZIP includes the same app and offline bilingual instructions. Check the attached SHA256SUMS file against your download. See the build metadata for the exact source revision and architectures.

Validation evidence and remaining limitations are in `docs/release-handoff.md`. Synthetic media export is verified separately from real hardware and human playback. Hardware clips are never uploaded.

LumaRec 1.0.0 使用 Apple 原生框架录制摄像头和麦克风并保存 MP4。普通用户无需安装 Homebrew、FFmpeg、Xcode 或其他运行环境，也不需要终端、账号或网络。

**当前为待验收候选包，稳定发布需完成交接记录中的验收项。** 应用仅有本地临时签名，未使用 Developer ID 签名，也未经过 Apple 公证。macOS 可能拦截首次启动；系统提供时可在“系统设置 → 隐私与安全性 → 仍要打开”中针对该应用正常允许。不要关闭系统安全机制。当前没有付费 Apple Developer 账号，不承诺公证。

通用应用支持 Apple 芯片及 Intel，最低 macOS 13。保留预览、电平、横竖屏、三档质量及暂停/继续；新增无声录制和可选择的失败素材恢复。原始素材保留至导出成功，导出不覆盖旧文件。系统声音仍需另行配置可选虚拟输入，基础麦克风录制无需驱动。
